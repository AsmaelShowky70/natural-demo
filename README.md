# نظام التتبع وسلسلة الإمداد للوجبات الخفيفة الطبيعية
## Natural Snacks Traceability & Supply Chain Enterprise System (Laravel 11 & PHP 8.2+)

نظام سحابي متكامل ومؤسسي لإدارة سلسلة الإمداد، التتبع العكسي والأمامي، محاكاة استدعاء الأزمات (Crisis Recall)، والرقابة على جودة تصنيع الأغذية الصحية، مبني بأحدث معايير **PHP 8.2+** وإطار عمل **Laravel 11** لتلبية احتياجات المصانع والشركات الغذائية الكبرى وجاهز للرفع الفوري على استضافة **Hostinger**.

---

### 🌐 دليل الرفع والتشغيل على استضافة هوستينجر (Hostinger Deployment Guide)

النظام مهيأ تماماً ليعمل على بيئة **Hostinger cPanel / hPanel** وقواعد بيانات **MySQL 8.0+ / MariaDB**:

#### 1. استيراد قاعدة البيانات بنقرة واحدة (One-Click Database Import):
- توجه إلى لوحة تحكم هوستينجر -> **قواعد بيانات MySQL (MySQL Databases)** وأنشئ قاعدة بيانات جديدة ومستخدماً لها.
- افتح **phpMyAdmin**، واختر قاعدة البيانات المنشأة، ثم اضغط على تبويب **استيراد (Import)**.
- اختر الملف الجاهز والمرفق بالمشروع:
  ```
  database/natural_snacks_mysql.sql
  ```
  *(يحتوي هذا الملف على بناء كافة الجداول الـ 25 مع البيانات الأولية وحسابات الإدارات جاهزة فوراً).*

#### 2. ضبط ملف البيئة (.env):
- في المجلد الجذري، ستجد الملف المهيأ مسبقاً: `.env.hostinger`
- قم بإعادة تسميته إلى `.env` (أو انسخ محتواه)، ثم حدد بيانات قاعدة البيانات المنشأة على هوستينجر:
  ```env
  DB_CONNECTION=mysql
  DB_HOST=127.0.0.1
  DB_PORT=3306
  DB_DATABASE=اسم_قاعدة_البيانات_في_هوستينجر
  DB_USERNAME=اسم_المستخدم_في_هوستينجر
  DB_PASSWORD=كلمة_المرور_السرية
  ```

#### 3. توجيه النطاق إلى مجلد public:
- في لوحة هوستينجر، تأكد من توجيه مجلد الموقع الرئيسي (Document Root) إلى مجلد `public` الخاص بلارافيل:
  ```
  public_html/public
  ```
  أو انقل محتويات مجلد `public` إلى `public_html` مع تعديل مسار `autoload.php` في `index.php`.

### 🛡️ الصلاحيات الصارمة وحصر كل دور في مجاله (Strict RBAC Isolation)

تم تطبيق نظام حماية مشدد عبر البرمجية الوسيطة `RoleMiddleware` وقوائم التنقل التفاعلية بحيث **يقوم كل قسم بمهامه المخصصة فقط** دون إمكانية التطفل على باقي الأقسام:

```
                  ┌──────────────────────────────────────────────┐
                  │          الإدارة العليا (Top Admin)           │
                  │   إشراف كامل + مستخدمين + تدقيق + تقارير      │
                  └───────┬──────────────┬──────────────┬────────┘
                          │              │              │
      ┌───────────────────┴──┐   ┌───────┴──────────┐   ┌┴───────────────────┐
      │   أمين المستودعات    │   │   مدير الإنتاج   │   │   مسؤول الجودة     │
      │    (Warehouse)       │   │   (Production)   │   │   (Quality/QC)     │
      ├──────────────────────┤   ├──────────────────┤   ├────────────────────┤
      │ • استلام التوريدات   │   │ • إنشاء التشغيل  │   │ • الفحص المخبري    │
      │ • رصيد الخامات والتعبئة│ │ • إدخال الفعليات │   │ • الإفراج النهائي   │
      │ • الجرد الفعلي الدوري│   │ • بطاقة السفر    │   │ • شهادات التحليل COA│
      │ • طباعة باركود اللوت │   │ • وصفات المنتجات │   │ • محاكي الاستدعاء  │
      │ ❌ محظور من الإنتاج  │   │ ❌ محظور من الاستلام│ │ ❌ محظور من إدخال  │
      │ ❌ محظور من الجودة   │   │ ❌ محظور من الجودة│ │   كميات الإنتاج     │
      └──────────────────────┘   └──────────────────┘   └────────────────────┘
```

#### تفصيل صلاحيات الأقسام الأربعة:

1. **أمين المستودعات (`warehouse@naturalsnacks.com`):**
   - **المسموح:** استلام شحنات الموردين (سندات GRN)، إدارة مخزن الخامات والتعبئة، الصرف لخطوط التشغيل، الجرد الفعلي للمخزون، وطباعة باركودات الشحنات.
   - **المحظور:** ممنوع تماماً من إنشاء أوامر تشغيل، أو تسجيل كميات الإنتاج، أو تنفيذ فحوص المختبر، أو الإفراج عن الباتشات، أو تعديل المستخدمين.

2. **مدير الإنتاج (`production@naturalsnacks.com`):**
   - **المسموح:** إنشاء أوامر تشغيل الباتشات، طباعة بطاقات السفر (Batch Traveler)، تسجيل الكميات الفعلية والكراتين والهالك، الاطلاع على وصفات المنتجات (BOM).
   - **المحظور:** ممنوع من استلام التوريدات، أو عمل الجرد المخزني، أو إجراء تحاليل الجودة والإفراج، أو الوصول لسجلات التدقيق والمستخدمين.

3. **مسؤول مراقبة الجودة والمختبر (`qc@naturalsnacks.com`):**
   - **المسموح:** استقبال إشعارات الفحص، تسجيل نتائج التحاليل (الرطوبة، الاختبارات الميكروبيولوجية، الغلق)، اعتماد الإفراج ونقل الرصيد، رفع شهادات التحليل (COA)، وتشغيل محاكي استدعاء الأزمات (Recall Simulator).
   - **المحظور:** ممنوع من تزييف أو إدخال كميات الإنتاج، وممنوع من إنشاء سندات الاستلام أو تعديل أرصدة المستودع.

4. **مدير النظام العام (`admin@naturalsnacks.com`):**
   - الصلاحية الشاملة على كافة الأقسام، إدارة المستخدمين وحساباتهم، ومراجعة سجل التدقيق الرقمي (Audit Trail).

> **ملاحظة أمنية:** في حال حاول أي مستخدم فتح رابط لا يقع ضمن صلاحياته، يتم تحويله فوراً إلى لوحة التحكم مع ظهور رسالة تنبيه واضحة: *"عذراً، هذا القسم غير مصرح لحسابك. يرجى الالتزام بالمهام والصلاحيات المخصصة لقسمك فقط."*

### 🎨 تحسين الشريط الجانبي وسلاسة التمرير (Sidebar Scrolling Fix)

تم حل مشكلة التمرير في القائمة الجانبية بنسبة 100%:
- تم تثبيت رأس الشريط (شعار المنظومة) وقاع الشريط (حقوق النظام) في أماكنهما.
- تم جعل جسم القائمة (`sidebar-scrollable-content`) يتمدد ويقبل التمرير الرأسي السلس (`overflow-y: auto`) مع شريط تمرير أنيق ونحيف مخصص (`custom scrollbar`).
- تعمل القائمة بانسيابية تامة على أي مقاس شاشة دون الحاجة إلى تصغير أو تكبير العرض.
